# CRM Front — Список выполненных апдейтов (2026-03-22)

Документ фиксирует, что было реализовано по обновлениям backend-контракта и UI за последние итерации.

## 1) Обновления по backend sync

### RBAC v2 и auth-context
- Переведена роль `manager` в полноценную роль фронта (без legacy-мэппинга `manager -> administrator`).
- Обновлены role helpers и матрица доступа по модулям:
  - `client` ограничен внутренними модулями;
  - `users` доступен только `administrator/manager` (и `superuser`).
- В модель auth-контекста добавлено поле `company_id` (`GET /api/v1/auth/me`).
- В профиле добавено отображение `ID компании`.

### BFF / API route handlers (Next.js)
Добавлены/расширены прокси-роуты под актуальный backend-контракт:

- Orders nested:
  - `GET/POST /api/orders/:id/documents`
  - `GET/POST /api/orders/:id/status-history`
  - `GET/POST /api/orders/:id/chat-messages`
  - `GET/PATCH /api/orders/:id/certificate`
- Trips nested:
  - `GET/POST /api/trips/:id/loading-points`
  - `PATCH /api/trips/:id/loading-points/:loadingPointId`
  - `GET/POST /api/trips/:id/path-points`
  - `PATCH /api/trips/:id/path-points/:tripPathPointId`
- Users admin:
  - `GET/POST /api/users`
  - `GET/PATCH /api/users/:userId`
  - `PATCH /api/users/:userId/password`
- Dictionaries / Settings:
  - `GET/POST /api/path-points`
  - `GET/PATCH/DELETE /api/path-points/:pointId`
  - `GET/POST /api/countries`
  - `GET/PATCH/DELETE /api/countries/:countryId`
  - `GET/POST /api/normative-documents`
  - `GET/PATCH/DELETE /api/normative-documents/:docId`
  - `GET/POST /api/email-templates`
  - `GET/PATCH/DELETE /api/email-templates/:templateId`

### Обновление frontend-типов
Добавлены/расширены типы:
- `AuthUser.company_id`
- `UserAdmin`, `UserWritePayload`, `UserFilterParams`
- `PathPoint`, `Country`, `NormativeDocument`, `EmailTemplate`
- соответствующие `*WritePayload` и `*FilterParams`

### Query keys
Расширен key-factory для новых модулей:
- `users.list/detail`
- `pathPoints.list/detail`
- `countries.list/detail`
- `normativeDocuments.list/detail`
- `emailTemplates.list/detail`

## 2) Новые UI-модули

Добавлены новые страницы приложения (`/(app)`):
- `/users`
- `/path-points`
- `/countries`
- `/normative-documents`
- `/email-templates`

Во всех модулях реализован единый каркас:
- заголовок + toolbar;
- фильтры (collapsible panel);
- серверная таблица с пагинацией/сортировкой;
- модалки create/edit;
- действия delete/reset-password там, где поддержано API;
- единая обработка ошибок backend через `detail`.

### Особенности users
- CRUD по пользователям с учетом RBAC;
- `manager` ограничен в назначении ролей (нет `administrator/manager`),
- `manager` не может выставлять `is_active=false` (UI-ограничение в формах),
- reset чужого пароля доступен только `administrator/superuser`.

## 3) UI/UX редизайн (референсный стиль)

- Обновлены AntD tokens и глобальный визуальный слой в «плоский» clean-enterprise стиль.
- Перестроен shell на верхнюю горизонтальную навигацию.
- Экран `/orders` приведен к композиции из референса:
  - верхняя action/search/filter строка,
  - status tabs,
  - action strip,
  - плотная табличная сетка.
- Приведены к единому визуальному паттерну остальные MVP-экраны.
