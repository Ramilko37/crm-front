# Wizard Create Order — изменения (MANAGER | ADMIN DELIVERY)

Дата: 18 апреля 2026
Ветка: `codex/order-create-backend-ui-20260408`
Коммит: `dfa3dba`

## Что изменилось на клиенте (UI / поведение)

### 1) Wizard-структура формы
- Большая create-форма разбита на 5 окон (шагов) в одном `Modal`:
  1. `Новый заказ`
  2. `Фабрика`
  3. `Данные заказа`
  4. `Товары`
  5. `Документы`
- Переходы:
  - кнопки `Назад` / `Далее` / `Готово`
  - переход по stepper
- Состояние хранится в одной `Form`-инстанции на странице (между шагами не теряется до закрытия/reload).
- Валидация на `Далее` выполняется только по полям текущего шага.

### 2) Шаги и порядок полей приведены к PNG-макету
- `Новый заказ`: `Компания` → `Имя клиента` → `Инвойс на другую компанию` → `Название компании` → `Ваша внутренняя нумерация` → `Тип заказа`.
- `Фабрика`: `Самодоставка`, единое поле `Назначить экспедитора`, `Страна`, `Фабрика`, `Адрес погрузки`, read-only `Индекс/Город`, контактные поля, `Email + Добавить`, `Контакт`, `Телефон`, `Дата готовности`, `Вывоз От/До`.
- `Данные заказа`: `Номер инвойса`, `Валюта`, `Другая валюта` (для `OTHER`), `Сумма`, `Заявленный объем, м3`, `Вес, кг`, `Кол-во мест`, блок `Перемер/Взвешивание`, read-only коэффициенты, `Сертификат (UI-only)`.
- `Товары`: `Добавить строку товара`, список goods lines, `Описание`, `Комментарий`, `Характеристики`, `Отметки офиса`, флаги `1С`, `Оплата через компанию`, `Проверен`, `Оплачено компанией`.
- `Документы`: `Добавить документ`, поля `Тип документа`, `Отображаемое имя`, `Выбрать файл`, финальная кнопка `Готово`.

### 3) UI-only поля (не уходят в backend)
- `certificate_intent`
- `new_factory_email_contact_name`
- `new_factory_email_contact_phone`

### 4) Доп. клиентская логика
- Для `Самодоставка` используется одно визуальное поле `Назначить экспедитора`:
  - при `self_delivery=true` работает с `self_delivery_forwarder_user_id`
  - иначе с `assigned_forwarder_user_id`
- При переключении режима самодоставки альтернативное поле экспедитора очищается.
- Добавлен read-only расчёт коэффициентов:
  - `Ценовой коэффициент = Сумма / Объем`
  - `Весовой коэффициент = Объем / Вес`

## Что изменилось в payload (что реально отправляется)

### 1) Контракт submit не менялся
- Отправка осталась прежней:
  - `payload` (JSON)
  - `documents` через multipart (`file_slot` + бинарные файлы)
- Публичные API/эндпоинты не менялись.

### 2) Бизнес-валидации перед submit сохранены
- required/if-then/XOR проверки create-flow остаются в `createMutation`.
- 422-mapping ошибок в поля формы сохранён.

### 3) Что НЕ отправляется
- UI-only поля (`certificate_intent`, `new_factory_email_contact_name`, `new_factory_email_contact_phone`) не включаются в backend payload.

- Убран UI-путь inline-create индексов/городов в wizard create-форме (не по макету).
